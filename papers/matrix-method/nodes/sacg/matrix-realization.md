# Main Content

Let $M$ be an $m\times r$ integer matrix with columns $y_1,\ldots,y_r\in\mathbb{Z}^m$.
Let $H_M=\langle y_1,\ldots,y_r\rangle$ be the subgroup of $\mathbb{Z}^m$ generated by the columns of $M$.

Define $G_M=\mathbb{Z}^m/H_M$ and $S_M=\{H_M\pm e_1,\ldots,H_M\pm e_m\}$, where $e_1,\ldots,e_m$ are the canonical basis vectors of $\mathbb{Z}^m$.

The *standardized abelian Cayley graph realized by $M$* is $X_M=\operatorname{Cay}(G_M,S_M)$.
By construction, $M$ is a Heuberger matrix of $X_M$.

## Remark

The graph $X_M$ is connected because the cosets $H_M+e_1,\ldots,H_M+e_m$ generate the quotient group $\mathbb{Z}^m/H_M$.

It has finite degree at most $2m$.

The graph can nevertheless have infinitely many vertices.
It is finite if and only if
\[\operatorname{rank}_{\mathbb{Q}}(M)=m.\]

If $e_i\in H_M$ for some $i$, then $H_M+e_i=H_M$, so $X_M$ has a loop at every vertex.

Distinct elements of $\{\pm e_1,\ldots,\pm e_m\}$ can determine the same coset modulo $H_M$.
Such coincidences reduce the degree of the graph but do not create multiple edges.

Different integer matrices can realize the same standardized abelian Cayley graph because different collections of columns can generate the same subgroup of $\mathbb{Z}^m$.

## Use in this paper

When the paper writes $M_X^{\mathrm{SACG}}$ without first specifying a graph $X$, it means that $X$ is the standardized abelian Cayley graph realized by $M_X$ through this construction.

Thus, if the columns of $M_X$ generate $H$, then
\[
M_X^{\mathrm{SACG}}
=
\operatorname{Cay}\left(\mathbb{Z}^m/H,\{H\pm e_1,\ldots,H\pm e_m\}\right).
\]

This construction allows the paper to define and study a graph directly from a finite integer matrix, even when the resulting graph has infinitely many vertices.
