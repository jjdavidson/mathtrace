# Main Content

Let $M_X=(y_1\ \cdots\ y_r)$ be a Heuberger matrix for a standardized abelian Cayley graph $X$, where $y_j=(y_{1j},\dots,y_{mj})^t\in\mathbb{Z}^m$.
For each $j\in\{1,\dots,r\}$, define the column sum
\[s_j=y_{1j}+\cdots+y_{mj}.\]
Then $X$ is bipartite if and only if every column sum $s_j$ is even.

## Proof

Suppose first that every column sum is even.
By repeatedly summing rows, we obtain a graph homomorphism
\[
(y_1\ \cdots\ y_r)^{\mathrm{SACG}}_X
\xrightarrow{\circledcirc}
(s_1\ \cdots\ s_r)^{\mathrm{SACG}}.
\]

If at least one $s_j$ is nonzero, then the operations in [[sacg.homomorphisms.matrix-homomorphisms]] give
\[
(s_1\ \cdots\ s_r)^{\mathrm{SACG}}
\xrightarrow{\circledcirc}
(2\ \cdots\ 2\ 0\ \cdots\ 0)^{\mathrm{SACG}}
=
(2)^{\mathrm{SACG}}_Y.
\]
The graph $Y$ is a single edge and therefore has chromatic number $2$ by [[sacg.one-by-one-classification]].

If every $s_j$ is zero, the same operations give a graph homomorphism
\[X\xrightarrow{\circledcirc}(0)^{\mathrm{SACG}}_Y,\]
where $Y$ is a doubly infinite path and again has chromatic number $2$.

In either case, [[graph.homomorphism-chromatic-number]] gives $\chi(X)\leq2$.
Since $X$ contains an edge, it follows that $\chi(X)=2$.

Conversely, suppose that $s_j$ is odd for some $j$.
Let $H$ be the subgroup generated by the columns of $M_X$.
Starting at any vertex, take $y_{1j}$ signed steps in the $e_1$-direction, followed by $y_{2j}$ signed steps in the $e_2$-direction, and continue through the $e_m$-direction.

Because $y_j\in H$, this walk returns to its starting vertex.
Its length is
\[|y_{1j}|+\cdots+|y_{mj}|,\]
which has the same parity as $s_j$ and is therefore odd.
Thus $X$ contains an odd closed walk and hence an odd cycle.
Therefore $X$ is not bipartite.
